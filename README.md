# Atlantis for Windows (`atlantis-win`)

Physical optical **Liquid Glass** Dynamic Island & desktop shell for **Windows 10 / 11**, powered by [`liquid-glass`](https://github.com/ziuus/liquid-glass) (`glass-core` + `glass-platform`) and `winit` (DX12 / Vulkan via WGPU).

## Ecosystem

| OS | Repository |
|---|---|
| **Linux / Wayland** | [`ziuus/atlantis`](https://github.com/ziuus/atlantis) |
| **Windows 10 / 11** | [`ziuus/atlantis-win`](https://github.com/ziuus/atlantis-win) |
| **Core Engine** | [`ziuus/liquid-glass`](https://github.com/ziuus/liquid-glass) |

## Quick Start (Windows)

```powershell
cargo build --release
cargo run --release
```
